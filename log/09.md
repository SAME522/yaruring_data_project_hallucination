# 9차시 — 할루시네이션 분류 모델 만들기와 비교

- **오늘 결정한 것:** 질문에 따른 할루시네이션 발생 여부는 **Yes/No를 맞히는 이진 분류 문제**다. 군집화는 질문 특징을 찾는 비지도학습 단계이며, 일반적인 연속값 회귀보다 분류가 목적에 맞다. **로지스틱 회귀·kNN·랜덤 포레스트** 3개를 같은 데이터(학습 3,605개/시험 902개, 난수 42)로 비교했다. 로지스틱 회귀는 시그모이드로 Yes 점수를 구하고, kNN은 가까운 질문의 투표를 이용하며, 랜덤 포레스트는 여러 결정트리의 판단을 종합한다. 기본 특징과 군집 특징 추가를 각각 시험하고 학습 데이터 내 5겹 교차검증으로 평가했다.

  | 모델(군집 포함) | 5겹 CV PR-AUC | 시험 ROC-AUC | 시험 Yes 재현율 |
  | --- | ---: | ---: | ---: |
  | 로지스틱 회귀 | **0.318** | **0.681** | **52.1%** |
  | 랜덤 포레스트 | 0.313 | 0.664 | 43.6% |
  | kNN | 0.291 | 0.604 | 3.1% |

  학습 교차검증의 PR-AUC를 기준으로 **로지스틱 회귀 + 군집 특징**을 우선 선택했다. 시험 데이터에서는 실제 Yes 163개 중 85개를 찾았지만, No를 Yes로 잘못 예측한 사례도 203개였다. 무조건 No라고 하는 기준 모델의 시험 정확도는 81.9%이지만 Yes 재현율은 0%여서 정확도만으로 평가하지 않기로 했다. `main.py`를 **데이터 탐색·전처리 / 모델 학습·성능 비교** 두 메뉴로 나눴다.

- **AI에게 보낸 프롬프트(원문):**
  > 이제 모델 제작과 분석을 진행해야 하는데 우린 진행해둔게 있으니 일단 그거 기반으로 진행해줘
  >
  > 보낸 사진은 예시로 준 모델들 사진인데 모델을 최소 3개 사용해야 한다니까 고려해서 선택하고
  >
  > 마지막으로 log3 참고해서 나머지 4,5,6,7,8, 다 3 번과 같이 간단하게 간추리고, 이후 지금 진행하는 내용 같은 방식으로 log9로 작성해 줘

- **AI가 준 것 중 고치거나 버린 것과 그 이유:** 이름만 보고 로지스틱 회귀를 연속값 회귀로 설명하는 방식을 고쳤다. 이 문제에서는 확률을 출력하는 **분류기**다. 군집 특징을 추가해도 성능 개선이 작아 무조건 유리하다고 결론 내리지 않았다. 시험 점수로 모델을 골라 과대평가하지 않도록 학습 교차검증 PR-AUC로 먼저 선택했다. kNN의 높은 정확도만 보고 좋은 모델이라고 판단하지 않았다.

- **느낀 점:** 여러 모델을 같은 기준으로 평가해야 특징이 드러난다는 것을 알게 됐다. 질문을 잘 분류하는 군집과 할루시네이션을 잘 예측하는 모델의 성능은 별개였고, 실제 Yes를 얼마나 찾는지도 중요했다.

- **AI 없이 내가 스스로 한 것:** 기존 군집화 결과를 버리지 않고 모델 비교에 활용하자고 결정했고, 수업에서 배운 모델 중 최소 3종을 사용해야 한다는 조건을 확인해 비교를 요청했다. 모델의 직접 실행·점검 등 내가 실제로 해 본 추가 작업은 이후 직접 확인하여 기록할 예정이다.
