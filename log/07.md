# 7차시 — 군집 품질 검증과 교차분석

- **오늘 결정한 것:** 단어 5,650개를 검토하고 의미 그룹 13개를 비교했다. 실루엣 계수는 약 0.045에서 0.124로 개선됐지만 여전히 낮았다. 질문군집 Q 6개와 의미 그룹 13개의 교차 조합 78개를 분석했다. 마지막에는 단어 90개를 하위 주제 8개로 재분류했으나, 5겹 검증 ROC-AUC가 TF-IDF 기준선 0.661에서 0.659로 소폭 낮아져 추가 세분화를 멈췄다.

- **AI에게 보낸 프롬프트(원문):**
  > 그럼 일단 만들어둔 군집의 품질부터 올려봐야겠네 그것부터 시작하자 부탁해
  >
  > 그러면 이제 수정된 군집을 기준으로 질문군집과 교차검증해서 테스트용 임시 군집을 만들고 테스트를 동시에 진행해 교차보완하는 방안은 어떨까

- **AI가 준 것 중 고치거나 버린 것과 그 이유:** 군집 개수와 실루엣만 보고 완성됐다고 판단하지 않았다. 교차군집 표본이 적은 경우 Yes 비율을 일반화하지 않았고, 예측 성능 향상이 없어서 군집 확대를 중단했다.

- **느낀 점:** 군집을 많이 만들수록 좋은 것은 아니었다. 목표인 할루시네이션 예측에 실제 도움이 되는지 확인하고 멈출 시점을 정해야 한다고 느꼈다.
