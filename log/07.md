# 7차시 — 단어군집 품질 개선과 질문·단어 군집 교차검증

> 2026-10-31에 진행한 연속 작업 중 세 번째 단계의 기록이다.

## 1. 오늘 결정한 것

군집을 더 많이 만드는 것보다 기존 군집의 품질과 활용 가능성을 먼저 확인하기로 했다. 문맥에서 함께 나타난 단어를 묶은 기존 W군집, 사람이 정한 주제 키워드 사전, 질문에서 단어가 수행하는 역할을 별개의 특성으로 구분했다. 예를 들어 같은 과학 관련 단어라도 '설명해 줘'와 '이야기를 만들어 줘'라는 요청에서는 다른 역할을 한다는 점을 고려했다.

학습 데이터에 등장한 어휘 5,650개를 통합해 검토하고, 비교적 자주 관측된 단어를 중심으로 13개 의미 그룹을 점검했다. 같은 단어 집합을 기준으로 기존 군집의 실루엣 계수는 약 0.045, 개선한 후보는 약 0.124로 높아졌다. 그러나 수치 자체는 낮고 사람의 주제 태그와 일치하는 비율도 약 40.4%에서 44.9%로 소폭 개선된 수준이므로, 이것을 완성된 의미 분류라고 해석하지 않았다.

이후 질문군집 6개와 의미 그룹 13개를 교차해 78개 조합을 분석했다. 이 중 52개는 학습 질문 30개 이상을 포함했지만, 10개 조합은 15개 미만이었다. 표본이 적은 조합의 Yes 비율을 일반적인 위험도로 단정하지 않기로 했다. 의미 그룹은 한 질문에 여러 개 속할 수 있으므로 각 그룹의 질문 수를 단순 합산하지 않았다.

마지막으로 혼합도가 높은 의미 그룹의 단어 186개를 재검토하여 90개를 8개의 세부 주제에 배정하고 96개는 원래 그룹에 남겼다. 해당 세부 주제가 나타난 학습 질문은 1,114개였다.

이 과정에서 예비 모델 비교도 진행해 군집이 실제 예측에 도움이 되는지 확인했다. 학습 데이터 내부 5겹 교차검증에서 TF-IDF 기준선의 ROC-AUC 평균은 약 0.661, 여기에 8개 세부 주제를 추가한 결과는 약 0.659였다. 군집을 더 세분화했지만 예측 성능이 개선되지는 않았다. 이 결과는 최종 시험 성능이 아니며, 따로 보류한 902개 시험 질문은 이번 후보 검토에 사용하지 않았다.

## 2. AI에게 보낸 프롬프트(원문)

> 단어 군집들 기준으로 만들어놓은거 한데 모아서 정리해볼래?

> 아 그거하자
> 세분화된 중첩 리스트마냥 군집을 넣은 군집을 만들어보자

> 뭔가 너무 산으로 간거 같은 기분이 드는데 어떤거 같아?

> 이 프로젝트의 중심이 되는 부분이 데이터를 분석하는 데에 있다는 걸 알아줬음 하는데
> 이를 고려해서 프로젝트를 검토해볼래?

> 그럼 일단 만들어둔 군집의 품질부터 올려봐야겠네 그것부터 시작하자 부탁해

> 일단 지금 만들어놓은 개별 군집 검토를 해서 수정을 한거잖아?
> 그러면 이제 수정된 군집을 기준으로 질문군집과 교차검증해서 테스트용 임시 군집을 만들고 테스트를 동시에 진행해 교차보완하는 방안은 어떨까

> 오케이 그럼 방금전 에 제안했던 방안으로 개선 한번만 더 진행해보자

## 3. AI가 준 것 중 고치거나 버린 것과 그 이유

- 단어의 주제와 문장 안에서의 역할을 하나의 군집으로 취급하는 방식을 수정했다. 주제·역할·비지도 군집은 서로 다른 기준이고, 같은 단어라도 사용 문맥이 달라질 수 있기 때문이다.
- 실루엣 계수의 개선만 보고 새 단어군집을 확정하지 않았다. 실제 의미의 정확성과 모델 예측 성능은 별도로 검토해야 한다.
- 78개 교차 조합 모두를 동일하게 해석하는 방식은 버렸다. 표본이 15개 미만인 조합은 비율 변동이 커질 수 있어 주의 대상으로 남겼다.
- 마지막 세분화에서 186개 중 96개를 무리하게 새 주제로 배정하지 않았다. 또 세부 주제를 추가해도 TF-IDF 기준선보다 ROC-AUC가 높아지지 않아 추가 군집화는 여기서 멈추기로 했다.

## 4. 느낀 점

군집을 계속 잘게 나누면 무조건 좋아질 것이라고 생각했지만, 검증을 해보니 분류가 복잡해지는 것과 예측에 도움이 되는 것은 다르다는 점이 분명해졌다. 내가 중간에 연구가 너무 산으로 가는 것 같다고 느낀 이유도 여기에 있었다. 그래서 군집 개수를 늘리는 작업에 임계점을 두고, 실제 데이터 분석과 모델 검증으로 넘어가는 편이 낫다고 판단했다. 무엇을 더 할지뿐 아니라 어디서 멈출지도 탐구에서 중요한 결정이라는 것을 배웠다.

내가 직접 판단한 부분: 군집을 끝없이 세분화하지 말자는 문제 제기, 기존 군집 품질부터 확인하자는 요청, 질문군집과 단어군집을 교차해 검증하자는 분석 방향의 제안.
