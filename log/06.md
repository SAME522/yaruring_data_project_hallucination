# 6차시 — 미분류 질문 재분류와 단계별 군집화

> 2026-10-31에 진행한 연속 작업 중 두 번째 단계의 기록이다.

## 1. 오늘 결정한 것

초기 질문군집에서 질문의 주제보다 create, list, generate, following, example 같은 일반적인 요청 단어가 큰 영향을 주고 있음을 확인했다. 이 다섯 단어의 영향만 줄여 군집을 다시 만들어 보았다. 특정 단어에 지나치게 집중된 군집은 6개 중 5개에서 2개로 줄었지만, 가장 큰 군집은 오히려 2,017개에서 2,734개로 커졌다. 한 가지 지표를 개선해도 전체 군집 품질이 좋아지는 것은 아니라는 점을 확인했다.

이렇게 만들어진 대형 수정 군집 Q′1(학습 질문 2,734개)을 대상으로, 질문의 주제를 직접 해석할 수 있도록 키워드 사전 기반의 임시 태그를 추가했다. 초기 7개 주제 그룹으로는 1,493개 질문이 미분류였으므로 기술·공학, 지리·국가, 교육·학습 등 7개 그룹을 추가해 총 14개 주제로 확장했다.

그 뒤에도 남은 1,138개는 TF-IDF와 HDBSCAN을 이용한 밀도 기반 군집화를 적용했다. 여기서 679개를 잠정 군집 후보로 묶고, 남은 459개를 조건을 조정해 다시 분석하여 291개를 추가 후보로 배정했다. 최종 168개는 근거가 부족해 미분류 상태로 남겼다.

| Q′1의 단계별 결과 | 새로 분류·배정된 질문 | 단계 종료 후 미분류 |
| --- | ---: | ---: |
| 7개 주제 사전 | 1,241개 | 1,493개 |
| 14개 주제 사전으로 확장 | 355개 추가 | 1,138개 |
| 밀도 기반 군집 후보 | 679개 | 459개 |
| 소군집 재분석 후보 | 291개 | 168개 |

위 숫자는 전체 4,507개가 아니라 수정된 대형 질문군집 Q′1의 학습 질문 2,734개를 대상으로 한다. 주제 사전 태그와 비지도 군집 후보는 서로 다른 분류 방법이며, 두 방법 모두 확정된 정답 분류는 아니다. Yes/No 라벨은 군집 배정 기준에 넣지 않았다.

## 2. AI에게 보낸 프롬프트(원문)

> 분류되지 않는 1000개정도를 기타로 치면 분석 결과에 어떨꺼 같아

> 그럼 다시 그 1000개가량의 오류를 군집화해볼래?

> 450 개를 다시 나눠봐

## 3. AI가 준 것 중 고치거나 버린 것과 그 이유

- 분류되지 않은 질문 약 1,000개를 전부 '기타'로 묶는 방안은 버렸다. 서로 다른 주제의 질문을 하나로 처리하면 추가 분석에 필요한 차이가 사라지기 때문이다.
- 공통 요청 단어를 가리는 시도는 일부 단어 집중도를 낮췄으나, 최대 군집 크기가 2,017개에서 2,734개로 늘어나는 부작용이 있었다. 그래서 이 결과만으로 개선이 끝났다고 판단하지 않았다.
- 459개를 다시 나눴더라도 모든 하위 군집에 의미 있는 이름을 붙이지 않았다. 추가 배정된 291개는 후보로 남기고, 명확한 근거가 부족한 168개는 억지로 분류하지 않았다.

## 4. 느낀 점

처음에는 미분류 질문을 '기타'로 두면 정리가 쉬울 것 같았지만, 그 안에도 서로 다른 주제가 섞여 있다는 사실이 마음에 걸렸다. 그래서 여러 차례 재분류를 진행했다. 숫자상 미분류가 줄어드는 것은 눈에 보였지만, 그것만으로 정확한 군집이라고 말할 수 없었다. 잘못된 분류를 늘리기보다는 판단이 어려운 질문을 그대로 남기는 것도 분석의 일부라는 점을 알게 되었다.
