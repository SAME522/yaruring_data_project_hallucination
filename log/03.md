데이터셋: HaluEval 1.0
출처: https://github.com/RUCAIBox/HaluEval

데이터 크기: 4,507행
열 개수: 전처리를 통해 6개 이상으로 구성 가능
수치형 열: 질문 글자 수, 단어 수, 고유 단어 수, 평균 단어 길이 등 4개 이상 생성 가능

예측 대상: 할루시네이션 발생 여부(Yes/No)

HaluEval 1.0 데이터셋을 활용하여 사용자 질문의 언어적 특징을 군집화하고, 로지스틱 회귀 모델로 할루시네이션 발생 여부를 예측하는 프로젝트를 진행하기로 결정했다.

질문 내용 : 
"네 판단에서 할루시네이션을 일으킬 수 있는 특정 단어를 추출해내는게 가능할 것이라고 생각해?"
"일단 정보들을 군집으로 정리한 뒤 회귀의 방식으로 예측하는 걸 원하고 있는데"

AI와 의 대화속에서 수정된 내용:
처음에는 개별 단어의 할루시네이션 발생률만 분석하려 했으나, 특정 단어가 할루시네이션을 직접 유발한다고 판단하기 어렵다는 한계를 발견했다.
따라서 단어별 발생률만으로 예측하는 방식을 보완하여 질문 전체의 특징을 군집화하고, 회귀 모델을 통해 예측 성능을 검증하는 방향으로 수정했다.
