2. JSON을 읽고 분석용 CSV 만들기

JSON 파일은 전체가 하나의 배열인 경우도 있고, 한 줄에 데이터 하나씩 기록한 JSONL 형식인 경우도 있어. 아래 코드는 두 형식을 모두 처리해.

import json
from pathlib import Path

import pandas as pd


# 파이썬 파일과 같은 폴더에 있는 데이터 읽기
folder = Path(__file__).resolve().parent
input_path = folder / "general_data.json"
text = input_path.read_text(encoding="utf-8-sig")

try:
    records = json.loads(text)
except json.JSONDecodeError:
    # 한 줄에 JSON 객체 하나씩 저장된 형식
    records = [
        json.loads(line)
        for line in text.splitlines()
        if line.strip()
    ]

if not isinstance(records, list):
    raise ValueError("데이터가 목록 형태인지 확인해 주세요.")

df = pd.DataFrame(records)

required = [
    "user_query",
    "chatgpt_response",
    "hallucination_label",
]

missing = [column for column in required if column not in df.columns]
if missing:
    raise ValueError(f"필요한 항목이 없습니다: {missing}")

2. 현재 탐구의 가장 큰 장점
마스터가 사용한 HaluEval 1.0은 AI가 실제로 생성한 응답에 대한 할루시네이션 판정 정보를 포함하고 있어.

지금 만든 엑셀을 통해 다음 질문을 탐구할 수 있지.

어떤 단어가 포함된 질문에서 할루시네이션이 자주 발생하는가?

특정 주제와 관련된 단어들이 비슷한 발생률을 보이는가?

질문의 길이와 할루시네이션 발생 사이에 관계가 있는가?

단어의 등장 횟수가 많아도 발생률이 낮은 사례는 무엇인가?

이러한 질문은 단순한 데이터 정리를 넘어 데이터에서 규칙과 경향성을 발견하는 탐구에 해당해.

4. 탐구를 완성하는 데 추천하는 3가지 분석
① 전체 평균 대비 발생률 비교

단어별 발생률과 전체 평균 18.08%의 차이를 계산해 연관성이 높은 단어를 찾아내는 거야.

② 단어를 의미별로 군집화

역사, 과학, 수학, 창작, 정보 검색 등 의미가 비슷한 단어들을 묶어서 어떤 질문 유형에서 할루시네이션이 많이 발생하는지 분석하는 방식이야.

③ 머신러닝 예측 모델 제작

질문의 단어와 길이 등을 바탕으로 할루시네이션 발생 여부를 예측하는 간단한 로지스틱 회귀 모델을 제작하고 정확도, 정밀도, 재현율, F1 점수를 측정하는 거야.

다만 이 세 가지를 모두 진행해야 좋은 탐구가 되는 건 아니야. 고2 수준의 데이터 분석 수행평가라면 ①과 ②를 충실하게 진행하는 것만으로도 충분한 탐구가 가능해.

2. 군집은 무엇을 기준으로 만들까?
여기서 마스터가 결정해야 할 중요한 부분이 있어.

군집화에는 크게 두 가지 방향이 있거든.

추천
A. 질문의 의미를 기준으로 군집화

비슷한 내용의 질문들을 하나의 군집으로 묶는 방식이야.

예를 들어 역사 관련 질문, 과학 관련 질문, 창작 관련 질문 등이 자연스럽게 묶이는지 확인할 수 있어.

이후 각 군집의 할루시네이션 발생률을 비교하는 거지.

장점: 군집의 의미를 해석하기 좋고, 질문 유형별 위험성을 분석할 수 있음.

B. 단어별 통계적 특징을 기준으로 군집화

지금 만든 엑셀의 단어별 등장 횟수와 발생률 등을 활용하는 방식이야.

예를 들어 자주 등장하는 단어, 드물지만 발생률이 높은 단어 등을 구분할 수 있어.

장점: 지금까지 만든 엑셀을 직접 활용하기 편리함.

다만 B 방식에는 큰 주의점이 있어.

할루시네이션 발생률을 이용해 군집을 만들고, 같은 데이터에서 그 군집으로 발생 여부를 예측하면 정답 정보가 모델에 미리 전달되는 데이터 누수가 발생할 수 있어.

따라서 예측 모델을 만들 목적이라면 A 방식이 더 적합해.

기존 연구 질문

사용자 질문의 어떤 단어가 할루시네이션 발생과 연관되어 있는가?

수정 추천 연구 질문

사용자 질문에 포함된 단어만으로 AI의 할루시네이션 발생 여부를 예측할 수 있는가?

이 질문이 좋은 이유는 명확해.

입력 데이터(X): 사용자 질문을 구성하는 단어

정답 데이터(y): 할루시네이션 Yes(1) / No(0)

머신러닝 목표: 질문의 단어를 분석해 Yes 또는 No 예측

평가 방법: 정확도, 정밀도, 재현율, F1 점수

3. 비교할 머신러닝 모델
모델

선택 이유

로지스틱 회귀

나이브 베이즈

텍스트 분류에 활용하기 좋은 기초 모델

랜덤 포레스트

단어들의 복잡한 관계를 학습할 수 있음

여기서 선생님이 요구한 베이스라인은 항상 No라고 예측하는 모델로 설정하면 돼.

전체 4,507개 질문 중 No가 3,692개이므로, 이 모델은 아무것도 학습하지 않고도 약 81.9%의 정확도를 기록할 수 있어.

따라서 정확도만 비교하면 안 되고, Yes를 얼마나 잘 찾아내는지 나타내는 재현율과 F1 점수도 중요해.

4. 5주 프로젝트 진행 계획
01
1주차 — 질문과 데이터 확정

HaluEval 원본의 4,507개 사례를 확보하고 연구 질문을 확정. GitHub 저장소와 README 작성.

02
2주차 — 데이터 전처리

질문을 단어별로 분리하고, 이상값·중복·결측치를 확인. 단어 빈도표 생성.

03
3주차 — 분류 모델 제작 및 비교

학습·시험 데이터 분할, 베이스라인 설정, 로지스틱 회귀와 다른 모델들을 비교.

04
4주차 — 결과 분석

성능 평가, 중요 단어 분석, 오분류 사례 확인, 모델의 한계 정리.

05
5주차 — 포스터 발표

A1 세로 포스터 제작 및 약 8분간의 개인 구술 평가 대비.

5. 특히 주의해야 할 평가 조건
사이트에서 가장 강조하는 부분은 다음과 같아.

AI가 코드를 작성하는 것은 허용돼.

주제 선정 이유와 결과 해석은 학생이 직접 작성해야 해.

모델을 여러 개 비교하고 선택 이유를 설명해야 해.

베이스라인보다 성능이 좋지 않아도 결과를 정직하게 기록해야 해.

GitHub에 코드 변경 과정, AI 대화, 차시별 기록을 남겨야 해.

최종적으로 포스터를 이용해 모델의 원리와 결과를 설명할 수 있어야 해.

특히 기존 엑셀은 전체 데이터를 대상으로 계산한 통계이므로, 모델 학습을 시작할 때는 원본 질문을 먼저 학습용·시험용으로 분할해야 해. 그렇지 않으면 시험 데이터의 정보가 학습 과정에 들어갈 수 있어.

내 최종 판단
마스터의 HaluEval 프로젝트는 이 수행평가에 적합하고, 기존 탐구도 그대로 살릴 수 있어.

지금까지 만든 단어별 발생률 엑셀은 탐색적 데이터 분석 자료로 활용하고, 여기에 질문 기반 할루시네이션 분류 모델을 추가하면 돼.

다만 성능이 실제로 얼마나 나올지는 아직 알 수 없어. 질문만으로 응답의 사실적 오류를 예측하는 데는 근본적인 한계가 있기 때문에, 예측이 어려웠다는 결과 자체도 중요한 연구 성과가 될 수 있거든.

내가 가장 추천하는 최종 주제는 다음과 같아.

「사용자 프롬프트의 언어적 특징을 활용한 AI 할루시네이션 발생 여부 예측과 분류 모델 성능 비교」

이제는 단순한 자료 조사보다는 실제 머신러닝 실험을 진행하는 방향으로 가면 좋겠어, 마스터.
